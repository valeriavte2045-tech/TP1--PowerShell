Descripción

Script de PowerShell que muestra información del sistema operativo, versión de PowerShell, política de ejecución y datos completos del sistema.

Contenido del script (InfoSistema.ps1)

# TRABAJO PRÁCTICO N°1 - Información del Sistema

Write-Host "=== VERSIÓN DE POWER SHELL ==="
$PSVersionTable

Write-Host "`n=== CONFIGURACIÓN DE PERMISIVIDAD ==="
Get-ExecutionPolicy -List

Write-Host "`n=== EDICIÓN DEL SISTEMA OPERATIVO ==="
Get-CimInstance Win32_OperatingSystem | Select-Object Caption, Version, BuildNumber, OSArchitecture

Write-Host "`n=== INFORMACIÓN COMPLETA DEL SISTEMA ==="
systeminfo
